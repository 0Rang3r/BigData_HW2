# BigData HW2

В этой папке находятся основные файлы, SQL-запросы и скриншоты по второму домашнему заданию BigData.

## 1. C++ binding

К первой домашней работе был добавлен C++ модуль на основе `pybind11`. Он используется для более быстрого сканирования JSONL-файлов и выполнения простых статистических расчётов.

## 2. ClickHouse

ClickHouse был установлен в WSL Ubuntu. В эксперименте были созданы две таблицы с одинаковой структурой:

- `logs_sorted`: `ORDER BY (user_id, event_time)`
- `logs_unsorted`: `ORDER BY tuple()`

В обе таблицы были загружены одинаковые сгенерированные пользовательские логи. В итоге каждая таблица содержит 27 000 000 строк, а объём данных в несжатом виде составляет около 55.35 GiB. Суммарный объём данных превышает 100 GiB.

## 3. SPU

SPU рассчитывался с интервалом сессии 1800 секунд. Результаты:

- `logs_sorted`: 2.34732
- `logs_unsorted`: 2.34732

## 4. Сравнение запросов

Результаты агрегирующего запроса:

- `logs_sorted`: 161 ms, прочитано 2 663 388 строк, 256.43 MiB
- `logs_unsorted`: 553 ms, прочитано 27 000 000 строк, 2.54 GiB

Из результатов видно, что при совпадении условий запроса с sorting key ClickHouse считывает меньше данных и выполняет запрос быстрее.

## 5. Визуализация

В Grafana были построены графики для сравнения времени выполнения запроса, количества прочитанных строк, объёма прочитанных данных и значения SPU.
